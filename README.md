# Secure TCP Client-Server Application

## Overview

This project is a secure TCP client-server application developed for the Network Programming module. The server is implemented in C and the client is implemented in Python. The system supports user authentication, session management, concurrent client handling, and security controls.

## Technologies Used

* C Programming
* Python
* TCP/IP Socket Programming
* Linux
* GCC
* Makefile

## Features

* TCP-based client-server communication
* Custom application protocol
* User registration and login
* Session token management
* Concurrent client handling using fork()
* Password hashing for secure authentication
* Rate limiting and brute-force protection
* Audit logging of client activities

## Project Structure

* Server Application (C)
* Client Application (Python)
* Makefile
* Log Files
